# v0.1.5

## Summary

Ajouter un service TypeScript autonome regroupant les opérations API Uber Eats retrouvées dans les ressources du site.

## Changes

- Création de `UberEatsApiService` avec 109 méthodes, un transport POST commun, la locale, la session du navigateur et l'annulation des requêtes.
- Types partiels pour les contrats observés ; corps explicites et réponses `unknown` pour les contrats non vérifiés.
- Catalogue sourcé distinguant les appels observés en réseau des références présentes dans les bundles.
- Contrôle TypeScript strict et tests du transport ajoutés aux commandes de validation existantes.
- Version synchronisée en 0.1.5. Le panneau conserve son lecteur JavaScript actuel.

## Validation

- Compilation TypeScript stricte et quatre tests du transport sur réponses fictives.
- Contrôles de format, manifeste et progression de version ; tests navigateur du panneau existant.
- Aucun appel métier de mutation exécuté pour valider les méthodes découvertes.

## Screenshots

Aucun changement de disposition. Les tests navigateur vérifient la version affichée et produisent les captures habituelles du panneau.
